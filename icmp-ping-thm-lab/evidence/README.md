# Evidence files

Add the screenshots captured by you; none were supplied with the chat, so this folder contains no fabricated evidence.

Recommended filenames:

- `thm-ping-result.png` — the TryHackMe terminal and completed task.
- `wireshark-icmp.png` — packet list with the `icmp` display filter.
- `wireshark-packet-details.png` — expanded IPv4 and ICMP details for a request or reply.

Before committing, crop or blur usernames, email addresses, public IPs that identify your connection, browser tabs, session tokens, and other personal data. Do not upload an unfiltered PCAP unless you have checked it for sensitive traffic; packet captures can contain private information.
